# Installer ISOs the template builds use (packer/). fetch.sh downloads one, checks it and uploads it
# to the datastore's ISO folder, where packer/ expects it.
#
# One per line:  <name>  <url>  <sha256, the URL of a checksum list naming the file, or - for none>  [file]
# [file]: the name to save it as, when the URL doesn't end with it (e.g. Microsoft's redirecting links).
# With -, fetch.sh prints the download's SHA-256: pin it here once you trust it.
# Bump a line when a new point release comes out, and the template's iso variable with it.
